# Conditional Routing Matrix (`C1`–`C11`, `B1`–`B6`, `J1`–`J4`)

Hackathon winning is **conditional**, never one-size-fits-all. An idea engineered to win a 4-week Solana Colosseum venture incubator (`Reflect`) loses on a 36-hour TreeHacks tabletop gym floor (`diffuji`). Always classify the room along **Condition**, **Sponsor Payoff**, and **Judge Archetype** before ideating.

---

## 3. Sponsor Benefit Vectors (`B1`–`B6`) & Judge Panel Archetypes (`J1`–`J4`)

When a sponsor puts up `$5k–$250k`, diagnose **which payoff they are buying** and **who is on the judging rubric**:

| Sponsor Benefit Vector (`query-brain --stats`, `N = 1,005`) | Observed Share | Judge Archetype Pair (`J1`–`J4`) | What Wins Their Heart Immediately |
| :--- | :---: | :--- | :--- |
| **`B2`: Day-Zero SDK Proof / Reference App** | **55.5%** (`558`) | **`J1` Core Protocol / SDK Engineers** | Making their new feature strictly load-bearing (`UniV4Backtester`, `AdFHE`, `Hardware Context Protocol`, `Clasp`). |
| **`B5`: Net-New Consumer/Merchant Trojan Horse** | **16.7%** (`168`) | **`J3` VCs / `J4` Fintech Execs** | Reaching non-crypto users via existing local rails (`ETHPark-QR`, `Ripe`, `Pregame`, `Omma Cash`, `Xelio`, `Pendiente`). |
| **`B4`: High-Volume TPS / Liquidity / Token Burn** | **8.2%** (`82`) | **`J2` Exchange / Quant / Infra Leads** | Turning passive capital/APIs into high-frequency on-chain loops (`Ore`, `Supersize`, `Supernova`, `Reflect`). |
| **`B3`: Eliminating Ecosystem Shame** | **7.3%** (`73`) | **`J1` Core Engineers / `J2` Quants** | Naming the sponsor's embarrassing flaw (`expensive storage` -> `TapeDrive`; `multichain key rot` -> `Cache Coherence`) and filing an honest DX bug log (`Vaticr`, `Redeye`). |
| **`B1`: Viral PR Spectacle (The Commercial)** | **7.0%** (`70`) | **`J3` VCs / Founders & `C1`/`C4` Expo** | A 15-second clip judges immediately film and share (`GibberLink` 50M+ views, `BananaBets` NFC wristband betting). |
| **`B6`: Practitioner & Domain-Expert Validation** | **5.4%** (`54`) | **`J4` Enterprise CTOs / MDs / Execs** | Built with/for real doctors, lawyers, vets, firefighters (`CrossBeam`, `MedKit`, `veTriage`, `Surgr`, `Prometeo`, `Eighty`). |
